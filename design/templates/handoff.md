# Design handoff

## Scope and approved direction

Project/branch/screen, user choice, preserved elements, what was not changed.

## Implementation

Files changed, reused components, states and main interaction.

## Actual verification

Exact command or interaction → observed result → final checkout/artifact.
Desktop/mobile visual evidence or explicit blocker. Persistence/denial evidence when relevant.

## Remaining decisions

Unmeasured checks, unresolved issues and user-owned decisions. Distinguish fixture data and live product behavior.

## Delivery state

Concept only / implementation candidate / local runtime-proven candidate / separately authorized release.
No implicit push, deployment, external upload or runtime installation.

For cross-agent development handoffs, retain the repository's existing `shared/templates/handoff.md` as the canonical delivery contract; this template is a UI-specific supplement, not a second live-state system.
